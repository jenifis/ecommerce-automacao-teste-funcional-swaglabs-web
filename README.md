# 🛒 E-commerce – Automação de Testes Funcionais (Swag Labs Web)

## 📌 Descrição

Este projeto tem como objetivo a automação de testes funcionais em uma aplicação web de e-commerce, utilizando o site **Swag Labs (Sauce Demo)** como sistema sob teste.  
O projeto valida os principais fluxos do usuário, garantindo o correto funcionamento das funcionalidades essenciais da aplicação.

---

## 🎯 Objetivo

- Automatizar testes funcionais de uma aplicação web de e-commerce  
- Validar fluxos críticos do usuário  
- Garantir qualidade e confiabilidade das funcionalidades  
- Servir como projeto de estudo e portfólio em automação de testes  

---

## 🧪 Escopo dos Testes

Os testes automatizados abrangem os seguintes cenários:

- Login com credenciais válidas e inválidas  
- Visualização da lista de produtos  
- Adição e remoção de produtos no carrinho  
- Acesso ao carrinho de compras  
- Processo de checkout  
- Finalização da compra  

---

## 🛠️ Tecnologias Utilizadas

- Linguagem de programação para automação  
- Framework de automação web  
- Framework de testes
